# C++ Banking System

A console-based banking application developed in C++ as an academic project.

## Features

- Provides a menu-based user interface
- Performs basic banking operations
- Uses functions to organize the program
- Uses loops and conditional statements
- Validates user input

## Technologies

- C++
- Console input and output

## How to Run

1. Download the `.cpp` file.
2. Compile it using a C++ compiler.
3. Run the compiled program in the terminal.

Example:

```bash
g++ banking_system.cpp -o banking_system
./banking_system
```
